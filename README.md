# Solar Monitoring System

A professional, high-performance web application designed for real-time monitoring and historical analysis of solar energy assets. Built with a focus on precision, security, and elegant user experience.

## 🌟 Key Features

### 🔐 Secure Authentication
- **Dual Login Methods**: Support for traditional username/password and OTP-based verification.
- **Enhanced Security**: Local storage "Remember Me" functionality utilizing XOR-based obfuscation to ensure passwords are never stored in raw plain text.
- **Session Management**: Secure logout and persistent session handling.

### 📊 Comprehensive Dashboard
- **Asset Overview**: Real-time status tracking for all connected solar devices (Online/Offline/Standby).
- **Background Synchronization**: Automatic 1-minute interval background updates to maintain accurate system status without interrupting user workflows.
- **Manual Refresh**: On-demand synchronization button with visual feedback for background tasks.

### 📈 Advanced Monitoring & Analytics
- **Real-time Telemetry**: Instant visualization of critical metrics including Voltage, Current, Power, and Temperature.
- **Historical Analysis**: Deep-dive into performance history with customizable date ranges.
- **Data Visualization**: Rich, interactive charts powered by Recharts for identifying trends and anomalies.

### 🔔 Event Management
- **Alert System**: Centralized view for system events, warnings, and critical alerts.
- **Filtering & Search**: Robust tools to quickly isolate specific events or time periods.

### 🛠️ Device Management
- **Lifecycle Control**: Seamlessly add, rename, and manage solar devices SN-by-SN.
- **Modular Configuration**: Per-device settings for output frequencies and operational parameters.

## 🚀 Tech Stack

- **Frontend**: React 18+ with Vite for ultra-fast development and optimized builds.
- **Language**: TypeScript for enterprise-grade type safety and reliability.
- **Styling**: Tailwind CSS for a modern, responsive utility-first design.
- **Animations**: Framer Motion for smooth, hardware-accelerated transitions.
- **Visuals**: Lucide React icons and Recharts for data visualization.
- **Utilities**: date-fns for complex temporal logic and offset management.
